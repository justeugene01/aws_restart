AWS re/Start: Python Practice

Python exercises from the Python module of the AWS re/Start programme Cohort 2, Apr 2026). Each script is a small, self-contained example of a core Python concept.

## Topics covered

| Script | What it shows |

| `hello_world.py` | Printing output |
| `string_data_type.py` | Working with strings |
| `numerical_data.py` | Numeric types: int, float, complex and bool |
| `categorise_values.py` | Checking the data type of mixed values |
| `collection_of_lists.py` | Lists, tuples and dictionaries |
| `conditionals.py` | `if / elif / else` with a post office menu and input checks |
| `for-loop.py` | Counting from 1 to 10 with a `for` loop |
| `while-loop.py` | Repeating with a `while` loop |
| `read_car_fleet.py` | Reading of `car_fleet.csv`

`car_fleet.csv` is the sample dataset used by the CSV script. `reStart-python-cloud9.tar` is an archive of the original course files.
